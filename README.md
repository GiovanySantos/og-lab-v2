# OG Lab

**An open-source, federated social network by cultivators, for cultivators.**

OG Lab is an independent fork of [Misskey](https://misskey-hub.net/), adapted
for the cultivator community. It builds on Misskey's federated social platform
and open-source work while developing its own identity and direction.

[Contribute to OG Lab](./CONTRIBUTING.md)

## Thanks

- [Codecov](https://about.codecov.io/for/open-source/) for code coverage.
