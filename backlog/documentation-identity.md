# Review project documentation and references

**Status:** Pending

## Goal

Align user-facing and contributor-facing documentation with the OG Lab identity
without obscuring that this project is a Misskey fork.

## Scope to review

- Update [CONTRIBUTING.md](../CONTRIBUTING.md) and its links to upstream
  contribution guides and community channels.
- Review [SECURITY.md](../SECURITY.md) so security reports point to the
  maintained OG Lab reporting channel.
- Replace the inherited [ROADMAP.md](../ROADMAP.md) with OG Lab priorities.
- Update the root [pull request template](../.github/pull_request_template.md)
  and the templates under `../.github/PULL_REQUEST_TEMPLATE/`.
- Review repository agent instructions and package documentation for
  user-facing identity references.

## Acceptance criteria

- User-facing project descriptions, support links, and contribution directions
  point to OG Lab-controlled resources where available.
- Misskey references needed for upstream attribution, licensing, protocol
  compatibility, package names, or inherited technical guidance remain accurate.
- Documentation does not imply that upstream Misskey channels or policies are
  operated by OG Lab.
